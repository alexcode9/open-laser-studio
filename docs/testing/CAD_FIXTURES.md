# CAD fixtures

Deterministic files in `tests/fixtures/cad/`, regenerated by:

```sh
node scripts/make-cad-fixtures.mjs
```

STEP headers use a fixed timestamp so the bytes are stable. Builders live in
`packages/cad-kernel/src/fixtures.ts`.

| File | Test | Expected |
| --- | --- | --- |
| `a-cylinder-30x150.step` | A | Analytical Ø30 × 150 mm cylinder along +Z, circumference πD |
| `b-stepped-shaft.step` | B | Ø30 × 80 + Ø20 × 50 coaxial; overall 130 mm; one axis candidate |
| `c-plate-with-hole.step` | C | 100 × 60 × 10 mm plate, Ø12 through-hole at (50, 30) |
| `d-rotated-cylinder.step` | D | Ø30 × 150, axis (1,2,2)/3 from (12, −7, 5); source coordinates unchanged by alignment |
| `e-cylinder-lowres.stl` / `-ascii.stl` | E | 16-segment mesh; units unconfirmed; fitted R ≈ 15 mm; mesh-derived area smaller than πDL |
| `f-plate-mm.step` / `f-plate-inch.step` | F | Same plate in mm and inches; identical millimetre bounds after normalisation |
| `g-assembly.step` | G | Pin translated +100 X, plate rotated 90° about Z; hierarchy preserved |
| `i-cube-10mm.3mf` / `i-cube-10inch.3mf` | 3MF | 10-unit cube; inch file becomes 254 mm |

Checksum mismatch of an embedded CAD file is Test H (`crates/laser-project` container tests): a
recoverable warning, no silent substitute.

## Suites

- Vitest `packages/cad-kernel/src/*.test.ts` — Tests A–G, 3MF units, section length, fit primitives
- Vitest `apps/desktop/electron/main/cad.test.ts` — CadHost import, cancel, timeout, restore
- Vitest `apps/desktop/electron/main/cad-milestone.test.ts` — pick → align → workpiece (needs native)
- Rust `laser-geometry` — `align_axis_to_rotary` vs `cad_alignment.json`
- Rust `laser-project` — schema v1 → v2, `.ols` round trip, Test H
- Playwright `apps/desktop/tests/e2e/cad.spec.ts` — import A, Ø30, Use as workpiece, save/reopen

Kernel tests load opencascade.js wasm (first `warmUp` up to 120 s). They do not talk to a laser.
